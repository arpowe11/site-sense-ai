# SiteSense AI 🧠🌐

**SiteSense AI** is an AI-powered assistant designed to answer web development and site-related questions. It provides developers and learners with fast, accurate, and contextual responses across both frontend and backend technologies. Powered by **OpenAI**, the same technology behind ChatGPT, SiteSense AI delivers high-quality answers, though like all AI models, it may occasionally generate incorrect or incomplete information. To explore how the AI works, including the API endpoint it uses to generate responses, check out the [backend](./backend) folder in the project repository.


## 🚀 Features

- 💡 Ask questions about HTML, CSS, JavaScript, Python, React, Django, and more
- 🤖 Natural language interface powered by AI
- 📚 Trained or fine-tuned on web development topics
- 🛠️ Easy to integrate with web apps or development environments


## 🧰 Tech Stack

- **Python** - Core programming language powering the backend logic
- **Flask**  – RESTful API framework used to handle requests and route AI responses to the frontend
- **OpenAI API / Langchain** – Powers the AI agent's natural language understanding and response generation
- **Postgres SQL** – Used to implement a custom caching layer for performance and cost efficiency
- **Frontend** - Built with PHP, HTML, CSS, and JavaScript for both the standalone plugin and embeddable widget


## 🛠️ About This Project

This project was originally developed during my **Summer 2024 internship** at **Sun Sign Designs** as part of my senior year at the **University of South Florida (USF)**. It was my **first AI-based application**, and I independently designed, built, and deployed the MVP.
